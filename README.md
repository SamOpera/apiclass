# env-site

Small Express website that loads `TESTING` and `KUNLE_API` from `.env` and displays them.

## Run (Windows cmd)

```
cd env-site
npm install
npm start
```

Then open http://localhost:3000

## .env

```
TESTING=12345
KUNLE_API=090807060504030201
PORT=3000
```

Change the values in `.env` and restart the server to see them update.
